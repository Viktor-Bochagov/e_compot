# Проект "E-compot"

## Описание
Проект ядра для интернет-магазина. 

## Использование

### Используемые в проекте классы:
- **Product**: Класс для описания товаров. 
- **Category**: Класс для описания категорий товаров. 
- **ProductIterator**: Класс, который перебирает все товары категории. Возвращает их по одному.
- **Smartphone** наследник класса Product. Описывает категорию товаров Смартфоны. Дополнен указанием модели, памяти и цвета.
- **Lawngrass** наследник класса Product. Описывает категорию товаров Трава газонная. Дополнен указанием страны-производителя, срока прорастания и цвета.
 

### Функции проекта:
- **object_creator_from_json**: Считывает данные из json-файла и создает объекты классов Category и Product. Делает это с помощью вспомогательных функций *json_reader* (считывает данные из json-файла) и *object_creator* (создает экземпляры классов Category и Product на основании поданных на вход данных)
